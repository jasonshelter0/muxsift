# MuxSift v0.2.0

本版本提供 Linux x86_64 CLI/TUI，新增网页媒体工作流和课程场景帧索引。

## 新功能

- `web URL -o DIR`：通过 yt-dlp 获取单个网页视频；加 `--asr buzz` 或 `--asr bcut` 继续转写 SRT 和 AI Markdown。
- `web --resume`：验证来源 URL 并复用已完成的媒体下载与后处理阶段；`--transcript-only` 可跳过 AI。
- TUI 可添加非 Bilibili 网页 URL，使用 Video 或 Transcript 模式；统一设置新增 yt-dlp 程序路径。
- `fetch` 保留为单独下载入口。
- `frames` 输出截图、JSON 时间线、Markdown 和可搜索的 HTML 索引，并可对齐 SRT。
- 实验性 `frames-proto` 使用 FFmpeg scdet、滚动自适应阈值、视觉哈希和直方图筛选候选帧，并输出选择原因；详见随包实验说明。

## 试用

```bash
./release/muxsift --version
./release/muxsift web 'https://www.youtube.com/watch?v=VIDEO_ID' -o ./web-notes \
  --asr buzz --buzz-project ~/Projects/buzz
./release/muxsift tui
```

yt-dlp 需要单独安装并加入 PATH，或通过 `--yt-dlp` / `download.yt_dlp` 指定。发行包提供 FFmpeg、aria2 和 Buzz bridge；Buzz 环境与模型需自行准备。AI 使用已有配置及环境变量中的 API key。Bcut 需要登录并上传音频。

## 验证与范围

- 工作区 34 项测试、Rust 格式和 Clippy 检查通过。
- 使用本地 HTTP 视频验证真实 yt-dlp 下载、恢复复用及 URL 不匹配时拒绝复用。
- 本次未对各网站在线下载及付费 AI 调用进行全面实测；网站可用性取决于安装的 yt-dlp、网络及站点访问要求。
- 当前一次处理单个网页视频，不处理完整播放列表，不读取 yt-dlp 用户配置；下载阶段仅显示阶段状态。未完成的下载失败后重新下载，完整下载可复用。
- `frames-proto` 属于可对比实验，仍需人工核对漏检和重复帧。macOS、Windows、正式 GUI 尚未交付。

下载 Linux 压缩包及同名 `.sha256` 文件，使用 `sha256sum -c` 校验后解压。v0.1.0 保留可用；本次发布来自独立功能分支。
